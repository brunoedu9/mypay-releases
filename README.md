# MyPay

Gestão e controle de recebimentos para Windows: atividades, recorrências, calendário, painel e relatórios, com os dados guardados no seu próprio computador.

## Baixar

Vá em **[Releases › mais recente](https://github.com/brunoedu9/mypay-releases/releases/latest)** e baixe o **`MyPay-Setup-<versão>.exe`**.

Depois de instalado, o MyPay se atualiza sozinho: ele avisa quando há versão nova e instala ao reiniciar.

Se o Windows mostrar **"O Windows protegeu o computador"**, clique em **Mais informações** › **Executar assim mesmo**. O aviso aparece porque o instalador ainda não tem assinatura digital.

## Privacidade

Seus dados ficam somente em `%APPDATA%\MyPay` e nunca são enviados para a internet. O app só acessa a rede para procurar atualizações neste repositório.
